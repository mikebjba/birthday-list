# The Birthday List

A simple, elegant React + Vite website showcasing Ebenezer's Birthday Wishlist with independent price controls and GTBank contribution details.

## Setup Instructions

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run locally:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

## Deploy to Vercel (1-Click Command)

```bash
npm install -g vercel
vercel
```
